# Typing Tester using Assembly Language

A console-based Typing Tester developed in **x86 Assembly Language** as a project for the **Computer Organization and Assembly Language (COAL)** course.

The project focuses on implementing a functional typing test while working with low-level programming concepts such as registers, memory, loops, procedures, string handling, keyboard input, and console output.

## Project Overview

The Typing Tester allows users to practice their typing and evaluate their performance through an interactive console-based interface.

The project was developed completely using Assembly Language to gain practical experience with low-level programming and computer organization concepts.

## Features

- Interactive typing test
- Text-based typing practice
- Time-based performance measurement
- Typing accuracy evaluation
- Typing performance results
- Console-based user interface
- Low-level implementation using Assembly Language

## Technologies Used

- **Assembly Language**
- **x86 Architecture**
- **MASM (Microsoft Macro Assembler)**
- **Visual Studio**
- **Windows**
